# ШІ-ключі: що завести і як

Коротко: код уміє працювати з 12 провайдерами. Жоден ключ не обов'язковий —
нема ключа, сходинка просто пропускається. Нема жодного ключа — картка
збирається без ШІ (детерміновано), прогін не падає.

**Ключі вводите ВИ САМІ. Нікому їх не пересилайте — ні в чат, ні в файл, ні в
код. Єдине правильне місце — GitHub Secrets.**

---

## 1. Куди класти

Репозиторій `prom-autopilot` -> **Settings** -> зліва **Secrets and variables**
-> **Actions** -> вкладка **Secrets** -> кнопка **New repository secret**.

- **Name** — точна назва з таблиці нижче, ВЕЛИКИМИ літерами, без пробілів.
  Назва має збігтися символ у символ, інакше прогін ключа просто не побачить.
- **Secret** — сам ключ.
- **Add secret**.

Після додавання GitHub більше не покаже значення — тільки назву. Це нормально.
Щоб замінити ключ, натисніть біля нього олівець і вставте новий.

Перевірити, що ключ підхопився: запустіть `add` з `live = 0` і подивіться
перший рядок логу — там друкується список сходинок, які бачить прогін.

---

## 2. Мінімум, з якого варто почати

Якщо не хочеться заводити все одразу — досить **двох**:

| Що завести | Назва секрета | Що дає |
|---|---|---|
| Google AI Studio | `GEMINI_API_KEY` | найкраща українська + одразу ДВІ сходинки (gemini і gemma працюють з одного ключа) |
| Cerebras | `CEREBRAS_API_KEY` | найшвидша перевірка; забирає аудит із дорогої моделі |

Цього вистачає на щоденну роботу. Решта — запас на повний перезалив каталогу.

## 3. Повна таблиця

Порядок у таблиці = порядок у сходах. Код завжди бере ПЕРШУ доступну сходинку,
і йде далі тільки коли попередня відмовила (429 / вичерпана квота).

| # | Провайдер | Назва секрета | Де взяти | Скільки безкоштовно |
|---|---|---|---|---|
| 1 | Google AI Studio | `GEMINI_API_KEY` | aistudio.google.com -> Get API key | ~500 запитів/добу на flash-lite |
| 2 | Google Gemma | *(той самий `GEMINI_API_KEY`)* | окремо заводити НЕ треба | 14 400/добу, але впирається в токени |
| 3 | Groq | `GROQ_API_KEY` | console.groq.com -> API Keys | ~1000/добу |
| 4 | Cerebras | `CEREBRAS_API_KEY` | cloud.cerebras.ai -> API Keys | 1 млн токенів/добу ≈ 400 карток |
| 5 | Mistral | `MISTRAL_API_KEY` | console.mistral.ai -> API Keys | великий місячний ліміт токенів |
| 6 | NVIDIA NIM | `NVIDIA_API_KEY` | build.nvidia.com -> Get API Key | 40 запитів/хв, добової стелі нема |
| 7 | Scaleway | `SCALEWAY_API_KEY` | console.scaleway.com -> Generative APIs | 1 млн токенів РАЗОВО (не щодня) |
| 8 | Cloudflare Workers AI | `CF_API_TOKEN` **+** `CF_ACCOUNT_ID` | dash.cloudflare.com -> AI -> Workers AI | 10 000 «нейронів»/добу |
| 9 | **Kilo Gateway** | **`KILO_API_KEY`** | kilo.ai -> Gateway -> API keys | ~200 запитів/ГОДИНУ |
| 10 | OpenRouter | `OPENROUTER_API_KEY` | openrouter.ai -> Keys | 50/добу (1000 після поповнення $10) |
| 11 | Cohere | `COHERE_API_KEY` | dashboard.cohere.com -> API Keys | 1000/МІСЯЦЬ ≈ 33/добу |
| 12 | **Vercel AI Gateway** | **`AI_GATEWAY_API_KEY`** | vercel.com -> AI Gateway -> API Keys | $5 кредитів/місяць (не запити) |
| 13 | GitHub Models | `GH_MODELS_TOKEN` | github.com -> Settings -> Developer settings -> Tokens | ~50/добу на Copilot Free |
| 14 | Anthropic | `ANTHROPIC_API_KEY` | console.anthropic.com | платний, стоїть останнім |

### Три місця, де легко помилитись

**Cloudflare — ДВА значення.** Один `CF_API_TOKEN` не працює: ID акаунта сидить
у самій адресі запиту. Без `CF_ACCOUNT_ID` сходинка сама себе вимикає і в лог
не потрапляє. ID акаунта видно у dash.cloudflare.com праворуч у бічній панелі
(або в адресному рядку після `/`).

**Kilo — ліміт по IP, а не по ключу.** Раннер GitHub Actions — спільна машина
Microsoft. Частину цієї години можуть з'їсти сторонні люди ще до нашого прогону.
Тому Kilo стоїть у сходах ЗАПАСНИМ, а не робочим. Заводити варто, але не
розраховувати на нього як на основний канал.

**Vercel — назва секрета `AI_GATEWAY_API_KEY`, не `VERCEL_AI_KEY`.** Я минулого
разу назвав вам `VERCEL_AI_KEY` — це моя помилка. У Vercel офіційна змінна
називається `AI_GATEWAY_API_KEY`, і саме її я прописав у код і в workflow. Якщо
ви вже завели секрет під старою назвою — перезаведіть під правильною, інакше
код його не побачить.

## 4. Vercel — єдине місце, де витрачаються гроші

Це не безкоштовний тариф, а **$5 кредитів на місяць**. Зате нема добової стелі
й моделі нормальні платні.

Арифметика: повний перезалив каталогу — це ~9800 запитів і ~29 млн токенів. На
`gemini-2.5-flash-lite` це приблизно **$3**. Тобто місячних кредитів вистачає
рівно на **один повний прохід каталогу на місяць**.

Захист від несподіваного рахунку тут не окремий вимикач, а сама конструкція:

- Vercel стоїть **дванадцятим** у сходах. Код завжди бере першу доступну
  сходинку. Дійти до Vercel можна тільки коли всі безкоштовні квоти вичерпані.
- **Нема секрета — нема витрат.** Без `AI_GATEWAY_API_KEY` сходинка для коду не
  існує взагалі.
- Тобто **наявність секрета і є вимикачем витрат**. Не хочете витрачати цього
  місяця — приберіть секрет, поверніть коли треба.

## 5. Необов'язково: керувати чергами вручну

Це вже **Variables**, не Secrets: Settings -> Secrets and variables -> Actions
-> вкладка **Variables** -> **New repository variable**.

Черг тепер ТРИ, бо на одну позицію йде до трьох викликів ШІ, і в них різна ціна
помилки:

| Змінна | Який виклик | Що там важливо |
|---|---|---|
| `AI_PROVIDERS` | створення картки | найкраща українська — дорога модель |
| `AI_PROVIDERS_AUDIT` | перевірка готової картки | лише уважність — дешева і швидка |
| `AI_PROVIDERS_FIX` | правка за зауваженнями | знову текст |

Значення — назви провайдерів через кому, малими літерами, у потрібному порядку.
Наприклад:

```
AI_PROVIDERS        = gemini,gemma,groq,cerebras
AI_PROVIDERS_AUDIT  = cerebras,groq,nvidia
AI_PROVIDERS_FIX    = groq,cerebras
```

**Порожня змінна = все працює само.** Не заводьте їх, поки нема конкретної
причини — вбудований порядок уже враховує і якість, і ліміти. Раніше черга була
одна, і дешева перевірка з'їдала квоту найкращої моделі; тепер аудит за
замовчуванням іде своєю чергою (спершу cerebras/groq/nvidia), навіть якщо ви
нічого не заводили.

Ще два вимикачі, якщо треба різко зекономити квоту (це змінні оточення, їх
задають у workflow, не в Variables):

- `AI_AUDIT=0` — вимкнути перевірку;
- `AI_FIX=0` — вимкнути другий прохід.

Разом вони повертають витрату до **1 запиту на позицію замість 3**.

## 6. Чого ШІ не бачить і не чіпає — ніколи

Це вшито в код, а не в промпт, тому не залежить від «слухняності» моделі:

- **Назовні не йде** ціна, собівартість, валюта, наявність, кількість. У аудиті
  стоїть БІЛИЙ список полів: навіть якщо завтра в картку додати нове грошове
  поле, воно не поїде до провайдера саме собою.
- **Записати ШІ може РІВНО 10 текстових полів**: дві назви, два набори
  пошукових запитів, два описи, два HTML-заголовки, два HTML-описи. Код товару,
  ціну, наявність, кількість, фото, групу, виробника, GTIN і характеристики він
  фізично не має чим торкнутись.
